This folder contains BuildAgent prefabs, to be used by skill. Each agent prefab attaches a BuldAgent script in Assets\\\_AMainGame\\Scripts\\Run\\Stats\\Agents. Use Assets\\\_AMainGame\\Prefabs\\Run\\BuildAgents\\SKill Build Agent.prefab as template, replace BuildAgentScriptPlaceholder with a real BuildAgent script.



Use existing LocalizedString when possible, but do not create new LocalizedString entries, just use the regular unlocalized fields if the need LocalizedString not available.

Title Group: name of the object that the skill applies to, for example: P0 Rock

Title: the effect of the skill, for example: Max Count (do not repeat the Title Group)
