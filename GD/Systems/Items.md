# Rock Flipper's GDD - Items

Items are dropped from chests.

Items have rarities, the same rarity system with Chests.

When an item is found, player earns cash, more rare items earn more cash.

# Item progression
Each item has level and item level bar.

Finding more of the same item to add exp to the item's level bar. When the level bar filled up, the item leveled up, the bar resets and gets harder to fill again.

When an item reached its max level, finding more of it only earns cash, won't level up it anymore.

Items of the same rarity have the same max level.

# Item effect
Items have effects that scale with their level.
