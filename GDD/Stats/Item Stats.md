# Item Stats

All stats of [items](../Systems/Items.md). Only cash value per find is upgradable; all other item stats are fixed and configured in Unity.

| Stat | Scope | Upgrade Direction |
|---|---|---|
| Cash value per find | Per rarity | _(+)_ |
| Item exp per find | Per rarity | Fixed |
| Max level | Per rarity | Fixed |
| Item effect stats | _Per individual_ | Fixed |
